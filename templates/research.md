# Research / compare / analyze

**Use this when:** you want options investigated, compared, or a recommendation.

**Template:**

```
Research <the question or decision>.

Scope / options to consider: <list the candidates, or "you suggest the main ones">.
Evaluation criteria (most important first):
- <criterion, e.g. cost>
- <criterion, e.g. learning curve>
- <criterion, e.g. ecosystem>

Depth: <quick overview / thorough analysis>.
Output:
- A comparison table across the criteria.
- A clear recommendation for my situation, with the main trade-off.
- <Cite sources / note assumptions, if relevant>

My context: <what makes my situation specific — budget, team size, constraints>.
```

**Tips:** ranking your criteria up front is what makes the recommendation actually fit
*you*. Ask for the trade-off, not just the winner.
