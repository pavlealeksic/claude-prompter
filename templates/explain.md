# Explain / learn a concept

**Use this when:** you want to understand something or be taught.

**Template:**

```
Explain <topic> to me.

My current level: <complete beginner / know the basics / intermediate>.
Depth I want: <quick intuition / solid working understanding / deep dive>.
Make it concrete: <use a simple analogy and at least one worked example>.

Format:
- Start with a one-paragraph plain-English overview.
- Then <step-by-step / key ideas / common pitfalls>.
- End with a tiny example I can try myself.

Avoid jargon unless you define it the first time you use it.
```

**Tips:** stating your current level is the single most useful detail — it stops the answer
from being too basic or too advanced. Ask for an example you can actually try.
