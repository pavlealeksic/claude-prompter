# Debug / fix something broken

**Use this when:** there's an error, a crash, or behavior that isn't what you expect.

**Template:**

```
Help me find and fix the root cause of this bug.

Symptom: <what's going wrong, in plain terms>.
Expected: <what should happen instead>.

Error / output:
```
<paste the exact error message, stack trace, or wrong output>
```

Environment: <language, framework, OS, versions if relevant>.
Steps to reproduce:
1. <step>
2. <step>

Already tried: <what you've attempted and what happened>.
Relevant code:
```
<paste the smallest snippet involved, or name the file>
```

Find the underlying cause before suggesting a fix. Explain what was wrong, then give the
corrected code and how to verify it's fixed.
```

**Tips:** paste the *exact* error and a minimal reproduction. Telling the model what you
already tried stops it from repeating dead ends.
