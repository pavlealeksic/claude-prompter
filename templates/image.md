# Generate an image

**Use this when:** you want to describe an image for an image-generation model.

**Template:**

```
<Subject: the main thing in the image, described concretely>,
<setting / background>,
<style: e.g. photorealistic, watercolor, 3D render, flat illustration, pixel art>,
<composition / shot: close-up, wide shot, top-down, rule-of-thirds>,
<lighting: soft daylight, golden hour, neon, studio>,
<mood / color palette>,
<level of detail / quality cues>.

Aspect ratio: <e.g. 16:9 / 1:1 / 9:16>.
Avoid: <things you don't want — text, extra limbs, clutter, specific colors>.
```

**Tips:** be concrete about subject, style, and lighting — vague prompts give generic
images. The "avoid" line (a negative prompt) is one of the strongest controls you have.
