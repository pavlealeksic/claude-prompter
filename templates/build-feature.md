# Build a feature / write code

**Use this when:** you want new code written — a function, component, script, endpoint, or
a whole feature.

**Template:**

```
Act as a senior <language/framework> developer.

Goal: <what to build, in one or two sentences>.

Context:
- Stack / environment: <language, framework, runtime, libraries>
- Where this lives: <file/module/service, or "new file">
- What already exists: <relevant existing code, data shapes, or APIs>

Requirements:
- <concrete behavior point>
- <input → output>
- <edge cases to handle>

Constraints:
- <style, performance, dependencies to avoid, security rules>

Output:
- The code, plus a short note on how to use it.
- <Include tests? yes/no>  <Explain key decisions? yes/no>
```

**Tips:** name the exact stack, give input/output examples, and say how you'll verify it
works (tests, a sample call). That single addition removes most guesswork.
