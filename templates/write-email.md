# Write an email or message

**Use this when:** you need to draft an email, DM, or other short written message.

**Template:**

```
Write a <email / Slack message / note> to <recipient and their role>.

Goal of the message: <what you want to happen as a result>.
Tone: <warm / professional / direct / apologetic / enthusiastic>.
Key points to include:
- <point>
- <point>

Length: <e.g. under 100 words>.
End with: <a clear call to action / a specific ask / next step>.

Context the reader needs: <anything they don't already know>.
```

**Tips:** lead with the goal (what you want them to *do*) and set the tone explicitly. A
length cap keeps it tight and respectful of the reader's time.
