# Summarize a document or conversation

**Use this when:** you want a long text, meeting, article, or thread condensed.

**Template:**

```
Summarize the text below for <audience: e.g. teammates who missed the meeting>.

Format:
- **TL;DR** — <1–2 sentences>
- <Key points / Decisions / Action items (owner → task → due date) — pick what fits>

Length: <e.g. under 200 words>.
Leave out: <small talk, tangents, anything irrelevant>.
Keep: <numbers, names, dates, commitments>.

Text:
```
<paste the content here>
```
```

**Tips:** naming the audience and the exact format (TL;DR vs. action items vs. bullets) is
what turns a vague summary into a useful one. Always cap the length.
