# Refactor / improve existing code

**Use this when:** the code works but you want it cleaner, faster, or better structured.

**Template:**

```
Refactor the code below.

Goal of the refactor: <readability / performance / smaller functions / remove duplication
/ better naming / testability>.

Must stay the same:
- External behavior and outputs.
- <public API / function signatures / file location, if they must not change>

Constraints:
- <no new dependencies / keep it in the same file / match existing style>

Code:
```
<paste the code, or name the file>
```

Explain what you changed and why. Don't change behavior or add features I didn't ask for.
```

**Tips:** the key line is "must stay the same" — it keeps a refactor from silently turning
into a rewrite. State the *one* improvement you care about most.
